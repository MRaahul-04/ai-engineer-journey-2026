Day 1 — Vectors & Matrices

Week 1 · Day 1 of 84 · AI Engineer Journey 2026

Why does ML even need this?

Machines don't understand "house" or "cat" — they only understand numbers arranged in structure. So step 1 of ML is always: turn everything into numbers.

Image → pixel values  |  Sentence → embedding numbers  |  House → feature numbers

Vector — Angle 1: a list

One house =
[1200, 3, 5, 85] → size, bedrooms, age, price

Order matters. Position 1 is always size, position 2 always bedrooms.

Vector — Angle 2: an arrow

[3, 2] means: start at origin, walk 3 right, 2 up, draw the arrow.
(0,0) ────────► has direction + length (magnitude)
Length = √(3² + 2²) ≈ 3.6   (Pythagoras!)

Same numbers, two lenses: data-row AND geometric-arrow — both true at once.

Matrix — many vectors, stacked

Matrix = stack of vectors, one row each. 
houses = [[1200, 3, 5, 85],
          [800,  2, 10, 55],
          [2000, 4, 2, 140],
          [950,  2, 8, 62]]
Shape (4, 4) → 4 houses (rows) × 4 features (columns)

Geometrically: each row is its own arrow — a matrix lets you operate on ALL those arrows in one shot.

NumPy indexing — the golden pattern

array[rows, columns]
  • houses[0] → row 0 as a vector → shape (4,)
  • houses[0:1] → row 0 as a matrix slice → shape (1,4)
  • houses[:, 3] → column 3 for every row (all prices)
  • houses[1, 2] → single value at row 1, col 2

Integer index vs. slice — the "why"

Integer index → "hand me the book itself" → dimension dropped
Slice → "hand me the shelf-section" → dimension kept, even if size 1

This is why ML models expecting batch shape (1, n) break if you accidentally hand them shape (n,).

Broadcasting gotcha

houses[0] == houses[0:1] does NOT give one True.
It compares element-by-element → [[True True True True]]

Want one final answer? Use .all() → (houses[0] == houses[0:1]).all() → True

Vectorization — the whole point

Slow (loop): processes one house at a time — Python interpreter overhead paid on every single row.

Fast (vectorized): houses[:, 3] / houses[:, 0] → whole operation pushed into compiled C code, all rows at once. 10–100x faster, and this is the exact pattern every ML training step reuses.

Cheat sheet

ConceptQuick meaning
Vectorone thing, described by numbers (or one arrow)
Matrixmany vectors, stacked into rows
Shape (n,)1-D vector, n elements
Shape (r, c)2-D matrix, r rows × c columns
array[i]integer index — drops a dimension
array[i:i+1]slice — keeps the dimension
