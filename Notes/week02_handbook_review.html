Day-by-Day: What Each Day Actually Built

Day 9 Logistic Regression

Linear Regression's line has no ceiling/floor — meaningless for probability. Sigmoid squashes any real number into (0,1), never touching the edges. SSE fails for classification (flat gradient on confident wrong answers); Binary Cross-Entropy fixes it with an unbounded penalty. The gradient Xᵀ(predictions−y) looks identical to Day 6's Linear Regression gradient — proven today to be no coincidence: log is exponential's exact inverse, so BCE's log and sigmoid's exponential cancel down to the same clean shape by design, not by accident.

Day 10 Classification Metrics

90% accuracy sounds great, hides everything. Confusion matrix splits every prediction into 4 boxes (TP/FP/FN/TN). Precision = "when I say yes, am I right?" Recall = "did I catch every real yes?" Proven mechanically that lowering the threshold trades Recall up for Precision down. F1 uses a harmonic mean specifically because a plain average lets one strong score hide one broken one.

Day 11 ROC Curve & AUC

Sweep the classification threshold across every value, plot TPR vs FPR, get one number (AUC) summarizing ranking quality regardless of threshold. AUC=0.5 is a coin flip, AUC=1.0 is perfect separation. Real debugging moment: sorting ROC points by FPR (a tie-prone column) before integrating silently corrupted the curve — fixed by sorting on threshold (guaranteed unique) instead. Generalized today to other places the same bug shape could hide (PR curves, kNN tie-breaking).

Day 12 Softmax Regression

Independent one-vs-rest sigmoids don't sum to 1 — no shared constraint. Softmax fixes this: exponentiate every score, divide by the shared sum, forcing all classes to compete for one 100% pie. Proven algebraically that sigmoid is softmax's exact 2-class special case. Same overflow trap as any exponential (fixed by subtracting the max first) and the same gradient-cancellation trick as Day 9, now generalized to a full weight matrix.

Day 13 Multiclass Metrics & Imbalance

Run Day 10's binary toolkit once per class, each taking a turn as "positive." Three ways to collapse per-class scores: Macro (plain mean, exposes minority failure), Micro (pooled, always equals accuracy), Weighted (mean by real class frequency). Proven with real 95/3/2 data: accuracy/micro/weighted all looked "fine" (~93–94%) while Macro F1 collapsed to 0.4562, correctly screaming that one class was a total failure. class_weight='balanced' fixes this by reweighting the loss — same underlying idea as Day 7's Ridge penalty, just retargeted at misclassification cost instead of large weights.

Day 14 kNN & Gaussian Naive Bayes

Two model families outside the regression lineage. kNN: compare to the k closest points, majority vote, no training at all ("lazy learner") — but its shared distance calculation means raw-scale features dominate (same canyon problem as Day 6/9, new mechanism) and majority-class points crowd out rare-class votes under imbalance. Gaussian NB: Bayes' Theorem + an independence assumption that's technically false but survives because classification only needs correct ranking, not calibrated exact probabilities — and because each feature's PDF is judged independently against its own mean/std, GNB doesn't need scaling and doesn't get diluted by imbalance the way kNN does. Head-to-head on the same 300/15/8 data: kNN Macro F1=0.51 vs GNB Macro F1=0.85 — the exact mechanism (shared space vs independent distributions) explained, not just observed.

Live Review Session — Correction That Mattered

Today's spot-check ran four cross-day questions instead of single-day recall — three landed cleanly, one surfaced a precision gap worth locking in.
Correction — Metric gap vs. root cause are two different lookups.
Said: a large Micro-vs-Macro F1 gap (e.g. 0.995 vs 0.61) implies you already know why — specifically, that False Negatives dominate.
Reality: the gap tells you a minority class is failing, and roughly how badly — it does not tell you whether the failure is FP-heavy or FN-heavy. That's a separate lookup, straight from Day 13's own formulas: fp = col_sum − tp, fn = row_sum − tp, read directly off the confusion matrix.
Locked-in version: Macro F1 vs Micro/Accuracy is a smoke detector — it tells you something's on fire and roughly how big. The confusion matrix is what tells you where the fire is. Never let a metric's size imply a mechanism you haven't actually verified against the raw matrix.
